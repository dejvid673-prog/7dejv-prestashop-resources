## Decyzja audytowa

Nie wykonano vendoringu. Przed ewentualnym importem trzeba:

1. sprawdzić cały zakres plików objętych licencją MIT,
2. porównać zasady z oficjalnym `.ai/CONTEXT.md` oraz dokumentacją PrestaShop 9,
3. przeprowadzić testy negatywne bezpieczeństwa i walidację struktury `SKILL.md`,
4. zachować `LICENSE`, pochodzenie i dokładny commit,
5. importować na osobnej gałęzi, bez automatycznej promocji do katalogu oficjalnego.
