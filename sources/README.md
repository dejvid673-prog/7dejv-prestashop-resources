## Polityka aktualizacji

1. Sprawdź najnowszy commit domyślnej gałęzi i różnicę względem zapisanej rewizji.
2. Sprawdź, czy zmieniła się licencja, struktura, nazwy skills lub wymagania wersji.
3. Przejrzyj instrukcje wykonujące backup, update, restore, zapis danych lub operacje sieciowe.
4. Zaktualizuj opis i raport audytu w jednym pull requeście.
5. Nie kopiuj kodu z upstream bez jednoznacznego prawa do redystrybucji.
